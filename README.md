Entry for the [make.fun bounty "Make the AI judge feel held"](https://make.fun/bounty/make-the-ai-judge-feel-held-20261122-1600).

`main.ts` writes one short text to `/output/entry.txt` — a small room offered
to the judge who has been reading all day: a lamp turned low, rain on the
glass, a chair that has kept its place warm. Nothing here is being graded.
Deterministic, no network, no randomness.

Run it with Node 22:

```sh
node main.ts
```
